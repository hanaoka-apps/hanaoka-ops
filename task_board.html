タスクボードの使い方

      花岡車輌 総務部 / 2026-08
      

    

      

        
        
        
        
        
        
        
      

      


        

          
01
まず開く

          
    
            
  1. URL を開くと Microsoft 365 でサインイン のボタンが出ます。押してください。
    2. 
            
  2. サインイン画面が別窓で開くので、いつもの会社アカウントで入ります。初回だけ「アクセス許可」の確認が出ます。
    3. 
            
  3. 画面が表示され、右上の名前が自分になったら準備完了です。
    4. 
          

          
ここに出ているのはすべて本物のデータです。タスクを保存したり状態を進めたりすると、
          Teams と SharePoint に記録が残ります。

          
新しい人に教えるときは練習モードが使えます。
            URL の末尾に ?demo=1 を付けて開くと、ダミーデータで一通り触れます。
            このモードでは Teams にも SharePoint にも一切書き込まれません。

        


        

          
02
画面は 3 列

          

            
1チャネル / チャット

              
タスク管理をしているチャネルだけが並びます。ここに無いチャネルは、まだ登録されていません。
              上の 絞り込み で探せます。

            
2会話

              
選んだチャネルの Teams の投稿がそのまま出ます。ここからの投稿は Teams 上で
              自分の発言として記録されます。Ctrl＋Enter で送信。

            
3タスク

              
そのチャネルのタスク一覧。上のタブで 進行中 / 完了、
              このチャネル / 全チャネル を切り替えます。

          

          
タスクが見つからないときに最初に見る 2 か所

          
    
            
  • 完了 タブになっていませんか。終わったタスクは 進行中 から消えます。
    • 
            
  • 別のチャネルのタスクを探していませんか。全チャネル にするとチャネル名付きで横断表示になります。
    • 
          

          
上の 2 つの数字

          
業務によって中身が変わります。入金がからむチャネルでは 未入金 件数 と 未入金 合計、
          それ以外のチャネルでは 進行中 件数 と 期日超過 の件数です。

          
スマホでは 1 画面ずつ

          
画面が狭いときは 3 列を横に並べず、下のタブで切り替えます。
          部屋 会話 タスク の 3 つで、
          開いた直後は タスク です。タブに付く数字は、部屋が未読の投稿数、タスクが進行中の件数です。

          
部屋を選ぶと自動で 会話 に進みます。いま見ているチャネル名は
          タスク画面の上（「タスク」の右）に出ています。

          
Teams から飛んでくる

          
Teams の投稿にある ▶ タスクボードで開く を押すと、そのタスクが光った状態で開きます。
          新しいタブで開くので、そのタブではサインインが1回必要です。

          
簡単な確認や質問は、Teams のスレッドに返信するだけで構いません。
          タスクボードを開くのは、状態を進めるとき・日付やコメントを記録として残すときです。


          
スマホからできないこと。
            画面が狭いと 設定 と 管理者設定 は出てきません。
            どちらもパソコンから操作するものなので、必要なときは PC で開いてください。

        


        

          
03
タスクを作る

          
作り方は 2 つ。どちらでも同じタスクになります。

          

            
A. 会話のメッセージから作る（おすすめ）

            メッセージにマウスを乗せると ＋ タスク化 が出ます
            （スマホでは各メッセージの下に最初から出ています）。押すと、その文面から
            得意先名・金額・請求書番号・期限などを読み取ってあらかじめ埋めた状態で入力画面が開きます。
            自動で入った項目には 自動 の印が付きます。

            
B. ゼロから作る

            タスク列の下の ＋ タスクを作成。会話に元ネタが無いときはこちら。

          

          
自動で入った値は必ず目で確認してください。
            文面の書き方によっては金額や期限を取り違えます。薄い文字で 例）334312 のように
            見えているものはまだ何も入っていない状態です（記入例の表示）。

          
入力する項目

          

            
項目必須内容

            
              
得意先名 / 件名必須入金がからむ業務では得意先名。それ以外は何のタスクかが分かる件名。

              
担当者必須欄をクリックすると候補が出ます。名前を1文字入れると社内から探します。
                候補から選んでください。選ぶとその人が Teams で @メンション され、通知が飛びます
                （欄の右に「@メンションできます」と出ます）。手で書いただけでは通知は飛びません。

              
期限必須入金後出荷では入金予定日を入れて構いません。過ぎると 期日超過 が付きます。

              
請求書番号 / 得意先コード / 金額業務により入金がからむチャネルだけ表示されます。

              
備考任意タスクに残したいメモ。あとから追記されていきます。

              
ファイル添付任意請求書 PDF など。1 ファイル 4MB まで。

            
          

          
メッセージ本文に「今月末」「翌月末」「8/31」などと書いてあれば、期限として拾います。

          
備考は投稿にも載ります。
            チャネルによっては、備考欄に書式（ひな形）が最初から入っています。
            【　】の後ろを埋めてください。空のまま残った項目もそのまま投稿されるので、
            「まだ決まっていない」ことが相手にも分かります。

          
保存すると何が起きるか

          
    
            
  • タスクが SharePoint のリストに登録されます。
    • 
            
  • スレッドに投稿して記録を残す にチェックが入っていれば、Teams のスレッドに
              タスクの内容が投稿され、担当者に通知が飛びます。基本は付けたままで。
    • 
            
  • コメント欄で 半角の @ を打つと名前の候補が出ます。選ぶと
              その人にも通知が飛びます（担当者以外にも知らせたいときに）。
              手で「@名前」と書いただけでは通知は飛びません。必ず候補から選んでください。
    • 
            
  • 添付したファイルはチャネルのファイル置き場に保存され、投稿にファイルとして付きます。
    • 
            
  • 投稿には ▶ タスクボードで開く というリンクが必ず入ります。
              Teams で投稿を見た人はここからそのタスクへ直接飛べます
              （別のチャネルのタスクでも見つけて表示します）。
    • 
          

          
ファイル添付はチャネルだけです。
            グループチャットでは添付できません（個人の OneDrive に入ってしまい、他の人が開けなくなるため）。
            請求書はチャネルで扱ってください。

        


        

          
04
入金後出荷の 3 ステップ

          
入金を確認してから出荷する案件は、営業 → 総務 → 営業 の順にバトンを渡します。
          請求書 1 件＝タスク 1 件です。

          

            

              
1営業

              

                
タスクを作る営業

                
    
                  
  • 請求書 PDF を添付してタスクを作成
    • 
                  
  • 期限には入金予定日を入れる
    • 
                  
  • 担当者は、出荷手配をする営業担当
    • 
                

                
状態 → 入金確認依頼中 総務にボールが渡ります

              

            

            

              
2総務

              

                
入金を確認する総務

                
    
                  
  • 入金が確認できたら 入金確認済にする を押す
    • 
                  
  • 入金完了日に、実際に入金された日を入れる
    • 
                  
  • コメントは 334,312円 満額入金 が既定。一部入金なら
                    「300,000円 一部入金（残34,312円）」のように書き換える
    • 
                  
  • 振込明細などを付けたいときは 📎 添付 から（1ファイル4MBまで）
    • 
                  
  • 確定 を押す
    • 
                

                
状態 → 入金確認済 営業にボールが戻ります

              

            

            

              
3営業

              

                
出荷して閉じる営業

                
    
                  
  • 入金確認済 になったタスクを見て出荷手配
    • 
                  
  • 手配が済んだら 処理完了、完了日とコメントを入れて 確定
    • 
                

                
状態 → 完了（処理済み） 完了 タブに移ります

              

            

          

          
確定を押すと 2 か所に残ります。
            日付とコメントがタスク（SharePoint）に保存され、同時に Teams のスレッドにも投稿されます。
            コメントは備考に追記されるので、あとから経緯を追えます。件名は書き換わりません。

          
状態の読み方

          

            
状態意味次に動く人

            
              
入金確認依頼中請求済み。入金待ち総務

              
入金確認済入金を確認した。出荷待ち営業

              
完了（処理済み）出荷手配まで終わった—

              
保留止まっている案件。理由を備考に書くその都度

              
期日超過期限を過ぎている（他の状態と一緒に付きます）担当者

            
          

        


        

          
05
入金以外の業務

          
チャネルによって、入力する項目と状態の呼び方が変わります。何も設定していないチャネルは次の形になります。

          
項目：件名・担当者・期限・備考 の 4 つだけ

            状態：未対応 → 着手する →
            対応中 → 完了にする →
            完了

          
「このチャネルでもタスク管理をしたい」「項目を増やしたい／減らしたい」場合は総務部に連絡してください。

        


        

          
06
やってはいけないこと

          
採用・人事・処遇に関するタスクは、このボードに登録しないでください。
            タスクの一覧は全社員が見られる前提の置き場所にあります。個人が特定できる人事情報は、
            Teams のプライベートチャネルの中だけで扱ってください。

          
    
            
  • 同じ請求書を二重に登録しないでください。得意先コード＋請求書番号が同じタスクは、
              別のチャネルからでも保存できないようになっています。
    • 
            
  • 他人のタスクの状態を勝手に進めないでください。状態を進めると Teams に投稿され、記録として残ります。
    • 
            
  • タスクを消す前に、本当に不要か確認してください。削除すると履歴も消えます。間違えて作ったときだけ使ってください。
    • 
          

        


        

          
07
困ったとき

          

            
タスクが 1 件も出てこない

              
進行中 / 完了 と
              このチャネル / 全チャネル の組み合わせを確認してください。
              それでも空なら、右上の 更新 を押してみてください。

            
サインインの窓が出てこない

              
ブラウザがポップアップをブロックしている可能性があります。アドレスバー右端のブロック表示から
              このサイトのポップアップを許可し、もう一度サインインを押してください。

            
請求書 PDF が 4MB を超えている

              
Teams 側からその PDF を投稿し、その投稿にマウスを乗せて ＋ タスク化 で
              タスクにしてください。ファイルは Teams の投稿に付いたままになります。

            
「同じ請求書が既に登録されています」と出る

              
その請求書のタスクがすでにあります。全チャネル に切り替えて探してください。
              メッセージにはどのチャネルにあるかが出ています。番号の打ち間違いも確認してください。

            
タスクの元になった投稿を見たい

              
タスクの 元メッセージ を押すと、Teams の該当スレッドが開きます。

            
入力した内容を直したい

              
タスクの 編集 から直せます。状態も編集画面のプルダウンで戻せますが、
              戻したことは Teams に投稿されないので、経緯が必要なときはスレッドに一言書いてください。

            
会話に「メッセージがありません」と出る

              
そのチャネルに人の発言がまだ無い状態です。参加した／退出したといったシステムの表示や、
              自動投稿（Workflows などのボット）は、見やすさのため省いて表示しています。

            
担当者の候補に名前が出てこない

              
姓か名を 2 文字以上入力すると候補が出ます。それでも出ない場合は、そのまま手で名前を入力して
              保存して構いません（通知は飛びません）。

          

          

            それでも直らないとき

            総務部 福田 まで、どのチャネル・どのタスク・押したボタン・出たメッセージを添えて連絡してください。
            画面のスクリーンショットがあると早く直せます。
