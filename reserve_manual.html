花岡車輌予約状況｜使い方

この画面でできること

デモ機と営業車の予約状況を、1週間ぶんまとめて見るための画面です。 誰がいつ何を使っているか、いま空いているものがあるかを確認できます。

タブ予約する場所この画面の役割
デモ機この画面（空きの枠をクリック）見る＋予約する
営業車Outlook（会議室と同じ手順）見るだけ
会議室Outlook / Teams（場所から選ぶ）見るだけ
全社員の予定Outlook（自分の予定表）見るだけ
スマホからも同じURLで開けます。営業車はスマホだと「その日の時間割」から始まります。

画面の読み方

縦が車両・機体、横が日付

左に並んでいるのが車両やデモ機です。右に伸びている帯が予約で、帯の位置と長さは実際の時刻に比例しています。 真ん中の点線が正午、赤い縦線が現在時刻です。

色の意味

色意味
予約まだ始まっていない予約
使用中いま使われている（デモ機は「貸出中」）
終了期間が過ぎた予約
重複あり同じものに期間の重なる予約が2件あります。総務部に連絡してください
取消取り消された予約
空きその週・その日に予約が1件もない

帯をクリックすると詳細（件名・期間・予約者・行き先）が出ます。帯が短くて文字が読めないときもクリックで確認できます。

行を見失わないために

  • マウスを乗せた行が薄い青になり、左端に青い縦棒が付きます
  • 横にスクロールしても左の名前は固定されたままです
  • 拠点や区分ごとに灰色の見出し行が入ります

週と日の切り替え

左上の 週 / 日 で切り替えます。日 は横が時刻になり、 当日の細かい時間帯を見るときはこちらが速いです。

週表示で日付をクリックすると、その日だけの時間割に切り替わります。 「週で全体を見て、混んでいる日に寄る」という見方ができます。 マウスを乗せると日付に下線が出るのが目印です。戻るときは左上の 週 を押してください。 この操作はデモ機・営業車・会議室・全社員の予定のすべてで同じです。

時間割の範囲はその日の予約に合わせて自動で広がります（営業車は6:00〜21:00、全社員の予定は8:00〜20:00が既定）。 早朝5時の予約があればそこまで伸びるので、範囲外に隠れて見えない予約はありません。 表の上に「5:00〜21:00」のように今の範囲が出ます。

日をまたぐ貸出や終日の休暇は、その日を丸ごと覆うので帯に「終日」と出ます。 帯をクリックすると正確な開始・終了の日時が分かります。

操作意味

最新かどうか

右上に「最終更新 14:32」と出ています。5分ごとに自動で取り直しますが、 すぐ確かめたいときは 🔄 更新 を押してください。

誰かに見せたいとき

週や拠点を切り替えるとURLが変わります。そのURLをTeamsに貼れば、相手も同じ週・同じ拠点の画面が開きます。

空きを探す

帯の隙間を目で探す必要はありません。上の「空きを探す」に開始と終了を入れて押すと、 その間ずっと空いているものだけが出ます。

  1. 開始と終了を入れる（例：8/25 13:00 〜 8/25 17:00）
  2. ボタンを押す
  3. 拠点ごとに緑のチップで空いているものが並ぶ。赤いチップは使用中で、 マウスを乗せると誰が使っているか出ます
  4. 検索した区間はマトリクス上に青い破線の帯で重なって見えます
チップをクリックどうなるか
営業車（緑・赤とも）その行が黄色くなってそこまでスクロール。絞り込みではありません
デモ機（緑）その機体をその期間で予約する画面が開きます（日時は入力済み）
デモ機（赤）その行が黄色くなる

解除を押すと、検索結果・黄色いハイライト・日付がすべて元に戻ります。

17:00に返す予約と17:00から始める予約は「重なっていない」と判定します。 同じ日に受け渡しできるようにするためです。1分でも重なっていれば重複です。

営業車を予約する

この画面からは予約できません。営業車の予約はこれまでどおり Outlook で行ってください。この画面はOutlookの予定を読んで表示しているだけです。

予約する

  1. Outlookで 新規 → 新しいイベント
  2. 件名を入れる
  3. 宛先に車両を追加する（例：営業車 大阪 エブリィバン）。 予約可能 と出ていればその時間は空いています
  4. 場所に行き先を入力する（例：轟産業 静岡支店）
  5. 日時を入れて 送信
  6. すぐに承諾のメールが返ってくれば予約完了です
Teams会議のトグルはOFFにしてください。 ONのままだと、Outlookが「場所」を「Microsoft Teams 会議」に上書きします。 そうなると入力した行き先が消えて、この画面にも出ません。車の予約にオンライン会議は不要です。
右側のスケジューラで赤くなっている時間帯は、すでに誰かが使っています。 空いている時間を探すなら「営業車」タブの空きを探すのほうが速いです。

変更・取消

Outlookでその予定を開いて変更・削除してください。この画面は5分以内に反映されます。

辞退のメールが返ってきたら

理由どうするか
すでに他の人が予約しているこれが本来の動作です。この画面で空いている車を探してください
先すぎる日付半年より先は予約できません。総務部に相談してください
何日にまたがる貸出でもそのまま1件で予約してください。 日をまたぐ出張も、期間をそのまま入れて構いません。 1日ずつ分けて予約すると、この画面では別々の予約に見えて実際の貸出期間が分からなくなります。

デモ機を予約する

デモ機はこの画面から予約します。

予約する

  1. 予約したい機体の行で、空いている日のマスをクリック（または空き検索の緑のチップをクリック）
  2. 件名・開始・終了を入れる。顧客名と行き先も入れておくと週間表で分かりやすくなります
  3. 「この機体の予約（前後30日）」に既存の予約が出ます。入力中の期間と重なる行は赤くなり、 重なっている間は「予約する」が押せません
  4. 「予約する」を押す

依頼者はサインインしているアカウントが自動で記録されます。入力は不要です。

同時に2人が同じ枠を取ろうとしたら

先に押した人だけが予約できます。後から押した人には画面にエラーが出て、予約は保存されません。 重複した予約が作られることはありません。

取消・変更

いまはこの画面から取消できません。総務部に連絡してください。

グレーの網掛けになっているマス

ショールーム機など持ち出しできないものです。クリックできません。

候補に出てこない機体がある

上の「部品・オプションを隠す」「予約対象外を隠す」のチェックを外すと全部出ます。 単独で貸し出す部品が候補に出てこない場合は総務部に連絡してください。

会議室の空きを見る

「会議室」タブは見るだけの画面です。予約は今までどおり Outlook か Teams の予定表で、 「場所」から会議室を選んで行ってください。この画面は全部屋の空きを一覧で見るためのものです。

まず上の「いま空いている部屋」を見る

画面の上に、今この瞬間から空いている部屋が収容人数つきで出ます。 30分 / 60分 / 120分で切り替えられます。急に打合せが必要になったときは、ここだけ見れば足ります。

その下に「使用中」の部屋と、いつまで使われているかが出ます。

先の日付を見る／人数で絞る

操作意味
週 / 日週は1週間の埋まり具合をひと目で。日はその日の時間割
すべての階建物・階で絞り込み（本社1F、工場など）
収容人数4人以上などで絞る。少人数の打合せで大会議室を取らないために
会議室名で検索部分一致。「LD」で LD-1〜LD-3 がまとまって出ます
予約がある部屋だけ使われている部屋だけ表示して縦を短くする
空いている部屋を探す日時を指定して、その区間に空いている部屋を一覧に出す
週表示の細い帯は、色だけで文字が出ません。1時間の会議は1週間の幅では十数ピクセルしかなく、 文字を入れると切れた数字が並んで読めなくなるためです。帯にマウスを乗せる（またはクリックする）と内容が出ます。 細かく見たいときは「日」に切り替えてください。

件名は表示していません

会議室の予定の件名は、この画面には出しません。 会議室には「○○さん面談」のような予定が入るため、全社員が見る画面に件名を出さない方針にしています。 代わりに誰が押さえているかを表示しています。

用途を知りたいときや、空けてほしいときは、帯をクリックしてください。 予約者の名前と、「Teams で聞く」「メールで聞く」のボタンが出ます。そこから直接聞いてください。

ただし、件名を隠しているのはこの画面だけです。 同じ予定は主催者本人の予定表にも入っているので、「全社員の予定」タブでは件名が見えます。 人に見せたくない予定は、必ず Outlook で「非公開」にしてください。それが唯一の確実な方法です。

予約者が出ない予約がある

次の場合は名前が出ず「使用中」とだけ表示されます。動作としては正常です。

  • 社外の人が主催している会議（名簿に無い人なので出せません）
  • 予約した人と同姓同名の人が社内にいる（どちらか分からないので出しません）
  • その部屋の空き情報が読めていない

Outlook で会議室の予定表を開くと、予約者名が分かることがあります。

「N室の空き情報が読めていません」と出た

その部屋は空いていても「予約なし」に見えます。 表を信じて予約すると重複します。Outlook で直接確認するか、総務部に連絡してください。

収容人数が出ない部屋がある

Exchange 側に収容人数が登録されていない部屋です。総務部で設定すると出るようになります。

全社員の予定を見る

「全社員の予定」タブは見るだけの画面です。他部署も含めた全員の予定を、 営業車と同じ形で日（時間割）と週で並べて見られます。 予定の登録・変更は、これまでどおり Outlook の自分の予定表で行ってください。

本文・添付ファイル見えない（読む権限もありません）

人に見せたくない予定は、Outlook で「非公開」にしてください。 Outlook で予定を開いて「非公開」（鍵のアイコン）を押すだけです。 この画面では「非公開」とだけ表示され、件名も場所も出ません。時間帯が埋まっていることだけが分かります。

帯に「終日」と出ているものは、その日を丸ごと覆う予定（終日休暇や連続した休みなど）です。 帯をクリックすると正確な開始・終了の日時が出ます。

打合せの相手を探す

  1. 上の「空いている人を探す」に日時を入れて「この区間で空いている人」を押す
  2. その時間に空いている人が部署ごとに緑のチップで出ます。予定がある人は赤いチップ（名前にマウスを乗せると何の予定か出ます）
  3. 名前をクリックすると、その人の行が黄色く光って表へスクロールします
  4. やり直すときは「解除」を押す

部署を絞ってから探すと見やすくなります。「予定がある人だけ」にチェックを入れると、 予定なしの人の行が消えて縦に短くなります。

その日の休みを一覧で見る

表の上に「不在・休暇」の帯が出ます。その日（週表示ならその週）に休んでいる人が名前で並ぶので、 朝いちばんに誰がいないかを確認するのに使えます。

この画面には出てこない人がいる

名簿は全社員のTeamsチームのメンバーから作っています。入社・退職はチームのメンバーに追従するので、 総務部が名簿を別に持つ必要はありません。チームに入っていない人は出てきません。 出てこない人がいたら総務部に連絡してください。

この画面のURLにはいま見ている日付・表示・絞り込みが入ります。 そのままコピーして送れば、相手も同じ画面を開けます。

困ったとき

全社員の予定タブで、件名がどの人も出ない
予定表の公開設定が足りていません。総務部に連絡してください。 （設定は全社まとめて変更するもので、個人の操作では直りません）
自分の予定を他の人に見られたくない
Outlook で予定を開いて「非公開」にしてください。 その予定は「非公開」と表示され、件名も場所も出なくなります。
会議室タブで、予約者の名前がどれも出ない
予約者は社員の予定の「場所」から突き合わせています。1件も出ないときは、 予定表の公開設定が足りていない可能性があります。総務部に連絡してください。
会議室を押さえた人に空けてもらいたい
会議室タブでその帯をクリックし、「Teams で聞く」を押してください。 日時と部屋名が入った状態でチャットが開きます。総務部を通す必要はありません。
サインインを求められる／画面が真っ白
会社のMicrosoftアカウントでサインインしてください。それでも出ないときは Ctrl と F5 を同時に押して読み込み直してください。
赤い帯で「重複予約が成立しました」と出た
総務部に連絡してください。本来起きないはずのことが起きています。 どちらかの予約を調整する必要があります。
「一部の車両の予約状況を取得できていません」と出た
その車両の行に「読めず」または「リスト」の印が付きます。 表示が古い可能性があるので、その車両については総務部に確認してください。
「いまは予約の登録ができません」と出た（デモ機）
閲覧はできますが登録ができない状態です。総務部に連絡してください。
予約したのに画面に出てこない
まず 🔄 更新 を押してください。営業車はOutlookで承諾メールが返っているかを確認してください。 辞退されていれば予約は成立していません。
時刻が9時間ずれている気がする
この画面はすべて日本時間で表示します。海外からアクセスしてもずれません。 ずれて見えるときは総務部に連絡してください。
総務部向け（管理者だけに出る操作）

管理者のアカウントでサインインすると、画面上部に準備状況パネルと保守ボタンが出ます。 利用者には出ません。

操作使う場面
占有情報を再構築履歴を直接いじった後。削除を先に、再構築を後に
予約対象を一括判定部品・オプションの予約対象フラグをまとめて設定する
表示名を日本語にする新しく作った列の表示名を直す

URLに ?admin=1 を付けると管理者以外でもパネルが出ます（切り分け用）。 逆に利用者の見え方を確認したいときは付けずに開いてください。
